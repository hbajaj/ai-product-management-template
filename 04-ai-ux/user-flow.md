## Entry point

**Signal type:** File / document uploaded

A user uploads or drops a transcript, or ticket export into Juno.

**What they see instantly**

A strategy .txt or .md file is uploaded into the Strategy Source column.
Instant surface response: Show the filename, word count, and “Source loaded / Juno is indexing strategy…” status immediately.

## The flow

1. Parse and index the uploaded document so Juno can retrieve relevant clauses.
Retrieve matching strategy evidence using search_strategy() based on the transcript insight.
Compare user pain against strategy and ticket context to assess severity, recurrence, and alignment.
Draft a priority recommendation with rationale and source traceability before any roadmap write is proposed.
2. “Parsing your inputs…” → “Searching strategy…” → “Cross-checking tickets…” → “Preparing recommendation…”
3. Path A · Understand: User asks what the evidence says → search_strategy() + read_tickets()
Path B · Recommend: User asks what should be prioritized → retrieve evidence, then draft_priority()
Path C · Commit: User wants the priority written to the roadmap → write_roadmap() and pause for human confirmation

## AI moments

**Placement:** Floating & Contextual

Priority insight cards with cited strategy evidence, rationale, and risk flags, plus an auto-drafted PRD v0.1 in the PRD Preview column.

Augmentation → Juno converts scattered evidence into a decision-ready priority and PRD draft, so the PM reviews and exercises judgment instead of manually gathering context and starting from scratch

## Fallbacks

**Kill switch**

Kill switch: Every Juno priority recommendation includes Approve, Edit, and Reject controls. The PM can change the proposed priority or reject it entirely, and any write_roadmap() action remains blocked until explicit human approval.

**Training signal**

Captured training signal: Every approve, edit, or reject is logged with the original recommendation, PM-corrected priority, rationale, supporting source clause, and timestamp. These become evaluation signals for improving future prioritization.

**Fail-safe**

Missing strategy → no strategic-alignment claim. Repeated tool failure → stop after 5 attempts and escalate. Turn limit reached → return the best current answer labeled “turn limit reached.” No roadmap write occurs without human approval.
